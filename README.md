# Job Cards

Карточки заданий по техническому обслуживанию с журналом выполнения.

Сайт защищён паролем: всё содержимое `index.html` зашифровано (AES-256-GCM, ключ из пароля через PBKDF2). Без пароля прочитать карточки или адрес журнала нельзя.

Отметки о выполнении хранятся в закрытой Google Таблице владельца. Запись и чтение проходят через Google Apps Script, который тоже проверяет пароль.
